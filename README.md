# HiFolio
iOS Application for High School Portfolios
This app allows students to showcase their highschool portfolio with many sections such as Education, Awards, Athletics, Arts, etc. 

This application uses Firebase Authentication, Firebase Database, and Firebase Storage. 

A mail account is required to create an account as the authentication is based on email.

Users open up the project to the login page where at the botton of the screen there is a prompt to sign up if it is their first time on the application. From there they can enter the mandatory fields, Email, Full Name, Password, and confirming said Password with adding a LinkedIn link being optional. To open up the sections there is an add button in the top right making the sections visible. From that point when opening up sections there will be an add entry button to add entries to said section. To Delete or Edit entries simply re-click on the entries in the portfolio view. To change profile picture the user can go into the settings view and click on their profile picture prompting their photos to open and allowing them to choose a photo to make their new profile picture.

There is no copyrighted images in this project as all images are from unrestricted SF Symbols that are copyright free and the logo was made using SF Symbols that were unrestricted and edited for the purpose of the logo.
